# Todo Task Manager

A responsive task management application developed using React.js. It provides an intuitive interface to create, update, delete, and organize tasks efficiently. The application uses React's `useReducer` Hook for centralized state management.

## Features

- **Create Tasks:** Add tasks with a title and description.
- **Edit Tasks:** Modify existing task details.
- **Delete Tasks:** Remove unwanted tasks.
- **Task Status Management:** Update tasks as Completed or Not Completed.
- **Task Filtering:** Filter tasks based on their completion status.
- **Responsive UI:** Optimized for desktop, tablet, and mobile devices.
- **State Management:** Implemented using React's `useReducer` Hook.

## Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| JavaScript (ES6+) | Application logic |
| HTML5 | Application structure |
| CSS3 | Styling and responsive design |
| useReducer | State management |

## Getting Started

Follow the instructions below to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/JayaJavaDev/React-Todo-Manager.git
```

**2. Navigate to the project directory**

```bash
cd React-Todo-Manager
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

## Application Overview

The Todo Task Manager provides essential task management operations through a simple and responsive interface. Users can create tasks, update task information, manage completion status, and filter tasks based on their current status.

React's `useReducer` Hook handles state updates through structured actions and a centralized reducer function.
